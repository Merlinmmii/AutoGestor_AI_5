# AutoGestor_AI_5
AutoGestor AI 5.0** es una plataforma autónoma diseñada para ejecutarse localmente mediante **Pinokio**. Funciona como un "Gobernador" central que orestra agentes, genera plugins dinámicamente usando IA local (Ollama), monitoriza recursos en tiempo real (CPU, RAM, GPU, Temperatura) y permite el diseño visual de workflows.
